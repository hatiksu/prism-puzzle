# Призма — головоломка со светом

Направь лучи света к кристаллам. Касание поворачивает зеркало, светоделитель пропускает луч и одновременно
отражает его, а цвета смешиваются как настоящий свет: красный + синий = пурпурный, все три — белый.
Каждому кристаллу нужен точно его цвет.

**Стек:** TypeScript, React 19, SVG, Motion, Web Audio API, Vite, vite-plugin-pwa, Vitest, Playwright.

## Возможности

- 24 уровня в четырёх главах — от одного луча на поле 5×5 до трёх цветов, делителей и стен на 7×8
- Звёзды за уровень: ★★★ — за минимальное число ходов, его считает решатель
- Подсказка показывает, какую деталь повернуть: решатель знает ближайшее решение из любой позиции
- Отмена хода (тоже считается ходом), перезапуск, прогресс и звёзды сохраняются на устройстве
- Уровень в адресе (`#7`): работает кнопка «Назад», закрытые уровни по ссылке не открываются
- Управление касанием, мышью и с клавиатуры (Tab + Enter), подписи для экранных дикторов
- Анимации поворота, свечение лучей, звуки синтезируются Web Audio, вибрация
- PWA: ставится на телефон и работает без интернета

## Как устроено

```
src/
├── game/                   логика без React
│   ├── types.ts            уровень, детали, цвета как биты RGB
│   ├── trace.ts            трассировка лучей: отражения, делители, стены, смешение цветов, защита от циклов
│   ├── solver.ts           решатель: все решения, минимум ходов, подсказка, звёзды
│   ├── generator.ts        генератор уровней с проверкой качества
│   ├── rng.ts              детерминированный генератор случайных чисел
│   ├── levels.json         24 готовых уровня
│   └── levels.ts           уровни и главы
├── hooks/usePuzzle.ts      состояние уровня: повороты, ходы, отмена, подсказка
├── components/             LevelSelect, PlayScreen, Board (SVG), TopBar, WinDialog, IconButton
└── lib/                    цвета, звук, сохранение прогресса
scripts/generate-levels.ts  генерация набора уровней
```

- **Решаемость по построению.** Генератор сначала выбирает «правильные» ориентации зеркал, пускает лучи и ставит
  кристаллы туда, куда свет действительно дошёл, а потом запутывает начальную позицию.
- **Решатель** перебирает все ориентации поворачиваемых деталей (у каждой две). Он отбраковывает уровни с кучей
  решений или слишком простые, считает минимум ходов (наименьшее число отличий от ближайшего решения) и даёт подсказки.
- **Уровни зафиксированы** в `levels.json`: игра у всех одинаковая. Тесты заново проверяют решателем каждый уровень.
- **Лучи на SVG:** каждый отрезок рисуется дважды — широкий размытый слой для свечения и тонкая линия. Режим смешения
  `screen` складывает цвета там, где лучи пересекаются.

## Команды

```bash
npm install      # зависимости
npm run dev      # dev-сервер
npm run build    # проверка типов и сборка в dist/
npm run preview  # собранная версия с Service Worker
npm run lint     # линтер
npm test         # unit-тесты (Vitest)
npm run test:e2e # E2E-тесты на компьютере и телефоне (Playwright)
npm run levels   # пересобрать набор уровней (несколько минут)
```

## Тесты

- **Unit (Vitest), 40 тестов:** правила отражения «/» и «\», светоделитель, стены и источники, смешение цветов и точное
  совпадение цвета, защита от зацикливания. Решатель: решения, минимум ходов, подсказки, звёзды. **Каждый из 24 уровней:**
  детали в поле и не пересекаются, сохранённое решение работает, начальная позиция не решена, минимум ходов совпадает
  с решателем, сложность растёт. Плюс детерминированность генератора.
- **E2E (Playwright, компьютер и iPhone 13), 16 тестов:** открытие уровней, три звезды и сохранение прогресса,
  меньше звёзд за лишние ходы, отмена и перезапуск, **прохождение уровня по одним подсказкам**, закрытый уровень по
  ссылке, управление с клавиатуры, работа без интернета.
- **CI:** `.github/workflows/ci.yml` на каждый пуш и PR запускает линтер, проверку типов, сборку и все тесты.
